Coding Standards

  • it('MEN-XXXX | description', () => { ... })
  • One file per Story: feature(MEN-XXX).cy.js
  • before() creates data · it() asserts only
  • loginViaApi() for speed · UI login only when required
  • Tags: @smoke @regression @men-XXXX
  • No hard waits > 3 seconds
